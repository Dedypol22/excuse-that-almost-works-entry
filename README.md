## The line

> sorry can't come in today, my car battery died, left the lights on all night somehow, mechanic's coming this afternoon

20 words, 118 characters, one line of plain text — specific, boring and
almost believable, with one small detail — the lights left on all night —
doing the quiet work. It passes the gate: 1–140 characters, one line,
at most 20 words, and reads like a real text sent in a hurry.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset), asserts the file content
matches the line exactly, and prints the line. Stdlib only, Python 3.13.
